# NeetCode Grind 

> Grinding until Big Tech stops ghosting.

---

## What is this?

This repo is my public evidence that I am in my algorithmic training arc.

Every file here represents one step closer to surviving technical interviews, explaining time complexity without panicking, and pretending I knew it was a hash map problem the whole time.

---

## Why does this exist?

Because one day I looked at a coding interview problem and thought:

“Yeah, I should probably stop avoiding dynamic programming.”

So now every NeetCode submission gets synced here automatically. Arrays, trees, graphs, sliding window, binary search, linked lists, recursion trauma — all of it lives here.

---

## Current mission

* Solve problems consistently
* Get better at pattern recognition
* Stop overthinking edge cases
* Learn to write cleaner code
* Prepare for internship and Big Tech interviews
* Become slightly less scared of dynamic programming
